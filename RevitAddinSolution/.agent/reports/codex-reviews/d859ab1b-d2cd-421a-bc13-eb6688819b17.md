- **P2**: `src/Antigravity.Core/Services/CadParserService.cs:139` - Square foundations are not deduplicated across quarter-turn rotations
  When Length and Width are equal, the same-dimension branch is selected and the swapped-dimension branch is skipped. The first branch does not treat a 90-degree rotation as equivalent, even though it represents the identical square. Duplicate square outlines whose rectangle extraction chooses axes 90 degrees apart therefore survive deduplication and can produce overlapping foundation instances. Normalize square rotations modulo PI/2, or evaluate swapped-axis equivalence independently rather than through else-if.
- **P2**: `src/Antigravity.Core/Services/CadParserService.cs:61` - Elevation grouping is order-dependent and quadratic
  Each line is assigned to the first group whose current average is within tolerance, and every comparison recomputes that group's average by enumerating all existing lines. Group membership consequently depends on geometry traversal order, and a group's elevation range can exceed the declared tolerance as its mean shifts. This can combine edges from distinct planes or split edges belonging to one plane, causing missing or incorrectly elevated foundations. It also makes a single large elevation group O(n^2), potentially freezing Revit on dense CAD imports. Use stable tolerance buckets or sorted clustering with cached group statistics and a bounded span.
- **P2**: `tests/Antigravity.Core.Geometry.Tests/CadParserServiceTests.cs:139` - Mock does not simulate type-creation failure

+            foreach (var loop in candidateLoops)
+            {
+                if (loop.Count < 2) continue;
+
+                var minZ = loop.Min(p => p.Z);
+                var maxZ = loop.Max(p => p.Z);
+                if (maxZ - minZ > 0.01) continue;
+
+                var loopSegments = new List<Segment2>();
+                for (int i = 0; i < loop.Count - 1; i++)
+                {
+                    loopSegments.Add(new Segment2(new Point2(loop[i].X, loop[i].Y), new Point2(loop[i + 1].X, loop[i + 1].Y)));
+                }

+                if (loop.First().DistanceTo(loop.Last()) > 0.001)
+                {
+                    loopSegments.Add(new Segment2(new Point2(loop.Last().X, loop.Last().Y), new Point2(loop.First().X, loop.First().Y)));

+                results.AddRange(ExtractFromSegments(loopSegments, elevation));
