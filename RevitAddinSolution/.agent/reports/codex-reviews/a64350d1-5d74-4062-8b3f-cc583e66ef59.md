# TECHNICAL_DESIGN.md

## Feature Definition
The "Auto Column Creator" is a WPF-based Revit add-in that automatically extracts geometric boundaries (rectangles and circles) from a selected CAD ImportInstance and places corresponding Revit Structural Column FamilyInstances.

## Architecture & Components
1. **AutoColumnCommand (src/Antigravity.Core/Commands/AutoColumnCommand.cs):**
   - Implements IExternalCommand.
   - Initializes the AutoColumnViewModel and passes it to the AutoColumnWindow.
   - Opens the AutoColumnWindow.

2. **UI Controls and Bindings (src/Antigravity.Core/Views/AutoColumnWindow.xaml & xaml.cs):**
   - **XAML View:** Flat design WPF window (No window frame, transparent background). Contains comboboxes for SelectedLevelBot, SelectedLevelTop, SelectedRectColumnFamily, SelectedCircleColumnFamily. Includes textboxes for OffsetBot and OffsetTop. Contains parameter mapping comboboxes for ParamB, ParamH, ParamDia.
   - **Code-behind:** Handles Window.DragMove() for dragging and close button clicks.

3. **View Model (src/Antigravity.Core/ViewModels/AutoColumnViewModel.cs):**
   - Implements INotifyPropertyChanged.
   - Dependencies: Document to fetch Levels and FamilySymbols (OST_StructuralColumns).
   - State Transitions: Upon initialization, populates AvailableLevels and AvailableColumnTypes. Handles user selection state.

4. **RevitEventHandler (src/Antigravity.Core/Services/AutoColumnRevitEventHandler.cs):**
   - Implements IExternalEventHandler.
   - Defines a thread-safe execution block to execute placement operations since WPF UI thread cannot mutate Revit documents.

5. **Column Placement Logic (src/Antigravity.Core/Services/RevitColumnPlacementAdapter.cs):**
   - Algorithm: Prompts user to select CAD ImportInstance -> Extracts Solid/GeometryObject (Lines/Arcs) -> Groups closed loops (Rectangles, Circles) -> Maps CAD geometry dimensions to Revit Column types (using ParamB, ParamH, ParamDia) -> Places Column instances using doc.Create.NewFamilyInstance(point, familySymbol, levelBot, StructuralType.Column).
   - Edge Cases: Ignored unclosed geometries. Handle cases where the selected parameter name does not exist on the FamilyType.

## Unresolved Decisions
- Should CAD blocks be supported alongside basic lines/arcs? Currently, we will stick to basic lines/arcs to match the "Draw Rect/Poly/Circle" mechanism.
