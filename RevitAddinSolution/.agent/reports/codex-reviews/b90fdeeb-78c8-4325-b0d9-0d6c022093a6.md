# TECHNICAL_DESIGN.md

## Feature Definition
The "Auto Column Creator" is a WPF-based Revit add-in that automatically extracts geometric boundaries (rectangles and circles) from a selected CAD ImportInstance and places corresponding Revit Structural Column FamilyInstances.

## Architecture & Components
1. **AutoColumnCommand (src/Antigravity.Core/Commands/AutoColumnCommand.cs):**
   - Implements IExternalCommand. Instantiates AutoColumnRevitEventHandler and ExternalEvent.Create().
   - Passes ExternalEvent to AutoColumnWindow. Shows window via Show() (modeless).
2. **UI Controls and Bindings:**
   - XAML View with properties: LevelBot, LevelTop, OffsetBot (mm), OffsetTop (mm).
3. **RevitEventHandler & Transaction Lifecycle:**
   - The handler's Execute(UIApplication app) runs in Revit API context.
   - It starts a single Transaction("Auto Column Placement").
   - Iterates through selected geometries, calls NewFamilyInstance.
   - Commits transaction if successful, calls RollBack() if exceptions occur.
4. **Top Constraint and Offsets:**
   - levelBot is passed to NewFamilyInstance.
   - Sets BuiltInParameter.FAMILY_BASE_LEVEL_OFFSET_PARAM using UnitUtils.ConvertToInternalUnits(OffsetBot, mm).
   - Sets BuiltInParameter.FAMILY_TOP_LEVEL_PARAM to levelTop.Id.
   - Sets BuiltInParameter.FAMILY_TOP_LEVEL_OFFSET_PARAM using UnitUtils.ConvertToInternalUnits(OffsetTop, mm).
5. **Dimension Mapping (Shared Family Types):**
   - Structural columns use Type parameters for B and H. 
   - Before placement, check if a FamilySymbol with exact dimensions exists. If not, ElementType.Duplicate(new_name) is called to create a new type (e.g., "60x80").
6. **CAD Geometry Extraction:**
   - Traverses ImportInstance.get_Geometry(Options). 
   - Applies ImportInstance.GetTransform() to all Curve elements to map CAD to Revit coordinates.
   - Groups curves that share endpoints (tolerance 0.001 ft).
   - If 4 orthogonal lines form a closed loop, classifies as Rectangle. If Arc is full 360, classifies as Circle.
